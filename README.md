# Aprendendo-com-a-IA


OBJETIVOS: 

Criar um caderno temático usando as ferramentas do notebookLM. A ideia desse caderno temático é aprender o que é um banco de dados relacional e como aplicar utilizando o software PostegreSQl. 

FONTES UTILIZADAS:

Utilizamos como fontes para o aprendizado de máquina, vídeos disponibilizados pelo youtube e documentações de sites oficiais como o do próprio PostegreSQL.
